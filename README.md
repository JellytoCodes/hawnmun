# Project Hawnmun

거점에서 장비를 준비하고 던전에 들어가 전투와 보스전을 거친 뒤, 보상을 정산하는 싱글 플레이 3D 액션 RPG입니다.

## 프로젝트 정보

- 개발 기간: 2026.03–2026.06
- 개발 인원: 6인 팀
- 담당 역할: 팀장 / 메인 프로그래머
- 개발 환경: Unreal Engine 5.7 · C++ / Blueprint

## 게임 흐름

- 거점에서 장비와 능력치를 정비하고 던전을 선택합니다.
- 던전에서 적과 보스를 상대하고 전리품을 모읍니다.
- 클리어하면 보상을 확정하고, 포기하면 거점으로 돌아옵니다.
